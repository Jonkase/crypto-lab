А-Я (33 буквы)

Теоретические основы классической криптографии

Все представленные шифры работают с русским алфавитом из 33 букв (от А=0 до Я=32). Ниже приведены математические законы и наглядная суть каждого алгоритма.

АТ

Шифр Атбаш

Древний шифр простой моноалфавитной подстановки. Алфавит записывается в обратном порядке: первая буква меняется на последнюю, вторая на предпоследнюю и так далее.

Математический закон:
ИНДЕКС_ВЫХОДА = 32 - ИНДЕКС_ВХОДА
Наглядные соответствия:
А (0) ➔ Я (32)Б (1) ➔ Ю (31)
В (2) ➔ Э (30)П (16) ➔ П (16)
Особенность: Шифрование и расшифрование выполняются по абсолютно одинаковой формуле.
ЦЗ

Шифр Цезаря

Шифр моноалфавитного сдвига. Каждая буква исходного текста смещается по алфавиту вправо на фиксированное число позиций (ключ К). При выходе за край (после Я) отсчет продолжается с буквы А.

Математический закон:
E(x) = (ИНДЕКС_ВХОДА + K) mod 33
Пример при сдвиге K = 3:
А (0) + 3 ➔ Г (3)
Э (30) + 3 ➔ А (0)
Я (32) + 3 ➔ В (2)
Для расшифровки значение сдвига вычитается: D(x) = (x - K + 33) mod 33.
ВЖ

Шифр Виженера

Полиалфавитный шифр. Использует ключевое слово. Каждая буква кодового слова определяет свой собственный величину сдвига (Цезаря) для соответствующей буквы исходного текста.

Математический закон:
E(x_i) = (ИНДЕКС_ТЕКСТА + ИНДЕКС_КЛЮЧА) mod 33
Пример для буквы 'М' при ключе 'К':
Текст: М (индекс 13)
Ключ: К (индекс 11)
Результат: (13 + 11) = 24 ➔ Буква 'Ш'
Если ключ короче текста, ключевое слово циклически повторяется.
